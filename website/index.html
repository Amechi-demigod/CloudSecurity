The platform

Four jobs. One place to do them.

Stop stitching together a cloud scanner, a vulnerability tool, an endpoint manager and an asset spreadsheet. Sentrigis brings them into one console with one view of risk.

CNAPP

Cloud security

Continuous, read-only posture scanning across your cloud accounts.

  • Misconfigurations mapped to CIS and Microsoft benchmarks
  • Full inventory of VMs, storage, databases, apps and identities
  • Internet exposure and attack paths to your crown jewels
Vulnerabilities

Vulnerability management

CVEs on cloud workloads and endpoints, ranked by real-world risk.

  • Known-exploited (CISA KEV) and EPSS likelihood first
  • "In use" detection separates live risk from dormant packages
  • Fix availability and the assets affected, in one list
Endpoints

Endpoint management

A lightweight agent for Windows, macOS and Linux.

  • Posture checks: encryption, antivirus, updates, firewall, screen lock
  • Lock, lost mode, remote wipe and network isolation

Every device from purchase to disposal, kept current by the agent.

How it works

Up and running in an afternoon.

No appliances, no agents in your cloud. A read-only connection for each cloud and a small agent on your devices.

1

Connect your cloud

Copy one script into Azure, AWS or Google Cloud Shell. It creates a read-only identity; Sentrigis tests it before saving.

az ad sp create-for-rbac \ --name cnapp-scanner --role Reader
2

Deploy the agent

Install a pre-configured package on Windows, macOS or Linux, or push it with your existing tools. Devices enrol themselves.

3

Fix what matters

Your first scan starts immediately. Prioritised findings, exposure and attack paths, with alerts to email, Teams or Slack.
