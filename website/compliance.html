Compliance coverage

See how your checks line up with the frameworks you answer to.

Sentrigis maps its automated checks to common security frameworks and shows the evidence per control.

Frameworks

CIS Benchmarks

Azure, AWS and Google Cloud foundations, AKS, EKS and GKE (the recommendations the cloud checks cover), plus CIS Critical Security Controls v8 endpoint and identity safeguards.

ISO/IEC 27001:2022 (Annex A)

Annex A controls mapped to the checks Sentrigis can evaluate automatically.

SOC 2 (2017 Trust Services Criteria)

Common criteria for Security, mapped to the same checks.

NIST Cybersecurity Framework 2.0

Subcategories mapped to the checks Sentrigis can evaluate automatically.

PCI DSS v4.0

Requirements mapped to the checks Sentrigis can evaluate automatically.

Evidence, not an audit opinion

Sentrigis never certifies anything. For each framework it shows which controls the automated checks pass, fail or only partly cover, which have nothing to evaluate, and which need manual evidence such as policies, people and supplier management. A score summarises only the controls that can be checked automatically; an auditor decides whether a control is met.

Filter by cloud account, see the trend over time, export CSV or PDF, and have the PDF emailed on a schedule.
