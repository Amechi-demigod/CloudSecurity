Scanned only with proof of ownership

The customer proves control.
A DNS TXT record or a verification file that only the domain's owner can add. IP addresses only if a verified domain points to them, they are in the customer's own cloud account, or a Sentrigis administrator approved them after the customer confirmed authorisation (recorded).
We check it again before every scan.
If the record or file has gone, the domain is skipped.
Private and reserved addresses are always refused.
Even if a domain points to one.

What it does and never does

Does

  • Connects to common service ports (TCP)
  • Reads service greetings and TLS certificate details
  • Checks web server security headers
  • Checks whether well-known sensitive files are exposed, reading at most 256 bytes and storing no contents

Never does

  • Exploits, injection or attack payloads
  • Attempts to break in or download data
  • Password guessing (only a short list of manufacturers' default passwords, and only when the system's owner switches that check on)
  • IPv6 or UDP scanning
