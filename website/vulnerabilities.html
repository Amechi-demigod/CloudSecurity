Vulnerabilities

Know which vulnerabilities to fix first, and how to fix them.

Sentrigis matches the software on your devices, Linux servers and network equipment against public vulnerability data, then ranks what it finds by real-world risk instead of severity alone.

Request a demo See fix guidance

Where it looks

Windows and macOS

Installed applications reported by the agent.

Linux servers

Installed packages, from the agent or the runtime sensor, on Debian, Ubuntu, RHEL, Rocky Linux, AlmaLinux and Alpine.

Network equipment

Firmware versions found by network scans.

Azure services

App runtimes and database engines past end of support.

What to fix first

Each vulnerability's risk combines its CVSS severity with whether it is on CISA's Known Exploited Vulnerabilities list, whether the affected asset can be reached from the internet, and whether it holds sensitive data. On servers running the runtime sensor, Sentrigis also checks whether the vulnerable package is actually loaded, so live risk stands apart from dormant packages. The EPSS likelihood of exploitation is shown alongside.

Fix-by dates

Every vulnerability gets a fix-by date based on its severity. Known-exploited vulnerabilities follow CISA's deadline.

Fix guidance

For each vulnerability, Sentrigis shows the fixed version and the devices affected, with the Windows update or application upgrade that resolves it. Download a PDF for a single vulnerability or a fix list for a device. Sentrigis tells you what to install; your existing tools install it.

Data sources

The NVD, OSV.dev, CISA's Known Exploited Vulnerabilities catalogue, FIRST EPSS and the Microsoft Security Update Guide. The data is cached, so matching keeps working if a source is briefly unavailable.
