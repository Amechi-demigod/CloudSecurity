Endpoints & servers

Keep laptops, desktops and Linux servers healthy and under control.

One lightweight agent reports each device's security posture, software and missing updates, and carries out remote actions only when an authorised person asks. High-risk actions also need a second admin's approval.

Request a demo See remote actions

Supported systems

Windows

Windows 10 and 11, installed from a pre-configured MSI package.

macOS

One package for Intel and Apple silicon Macs.

Linux servers

Ubuntu 20.04 to 24.04, Debian 11 and 12, RHEL, Rocky Linux and AlmaLinux 8 and 9, and Amazon Linux 2023. Packages for x86-64 and Arm64.

Posture checks

Every device reports the settings that matter, and anything out of line becomes an issue with a severity.

Windows

Disk encryption, firewall, antivirus, Secure Boot, TPM, OS updates, screen lock and local administrators.

macOS

FileVault, firewall, Gatekeeper, System Integrity Protection, XProtect, screen lock, OS updates and local administrators.

Linux servers

Security updates, pending reboots, automatic updates, firewall, disk encryption, SSH root and password login, admin accounts, SELinux or AppArmor, auditd, time sync, listening ports and installed packages.

Remote actions, with approvals

Every action needs a reason and is written to the audit log. Wipes and higher-risk scripts need a second admin to approve, and unapproved requests expire after 24 hours.

Lock and lost mode

Windows and macOS.

Suspend sign-in

Signs users out and blocks sign-in until you restore it. Windows and macOS.

Remote wipe

Windows devices that were set up to allow it at install time.

Signed scripts

PowerShell on Windows, zsh or bash on macOS. Only scripts you have signed can run.

Remote support

View-only or full control, and only after the user accepts. Windows.

Linux servers

Re-run checks, collect logs and restart the agent. No lock or wipe on servers.

Missing updates and software

Sentrigis lists the Windows updates each device is missing, checked through Windows Update or WSUS about every 12 hours, plus the software installed on every Windows, macOS and Linux device. It reports what is missing; your existing tools install it.

Runtime detection for Linux servers

Add the Sentrigis runtime sensor to Linux servers, VMs or Kubernetes nodes (as a service or a DaemonSet). It watches processes, network connections and file access, and flags reverse shells, crypto miners, privilege escalation, access to credential files, shells inside containers and cloud metadata access from containers, mapped to MITRE ATT&CK. It only observes and never blocks.

Deployment and updates

Download a pre-configured package and push it with Group Policy, Intune, SCCM, Jamf or Kandji, or install it by hand. Devices enrol themselves. Agent updates are signed and roll out in stages, starting with a pilot group, and pause automatically if something goes wrong.
