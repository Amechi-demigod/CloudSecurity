Cloud security

Find the misconfigurations and exposure in your cloud, without changing a thing.

Sentrigis connects to Azure, AWS and Google Cloud with read-only access, scans on a schedule, and shows what is open to the internet and how an attacker could reach your data.

Request a demo How read-only access works

What it checks

Every scan refreshes a full inventory of your cloud resources and runs 134 posture checks against it.

Posture checks

Misconfigurations across Azure, AWS and Google Cloud, tagged to the CIS Benchmarks, the Microsoft cloud security benchmark and AWS Foundational Security Best Practices.

Cloud inventory

Virtual machines, storage, databases, serverless functions, key vaults, identities and network controls, kept current by every scan.

Kubernetes

Control-plane checks for AKS, EKS and GKE, such as public API endpoints, RBAC and audit logging.

End-of-life software

Azure app runtimes and database engines that are past end of support.

Exposure and attack paths

Knowing a resource is misconfigured is half the picture. Sentrigis also shows whether it can be reached.

Internet exposure

Which ports are reachable from the internet once the network controls in front of each resource are taken into account. On Azure that includes network security groups, load balancers, application gateways and Azure Firewall.

Attack paths

Routes from the internet, through an exposed resource, to a store of sensitive data, marked as confirmed or possible.

Risk score

Findings, critical vulnerabilities, runtime alerts and attack paths combine into one 0 to 100 score, so you can see whether things are getting better.

Compliance and reports

Results map to CIS, ISO 27001:2022, SOC 2, NIST CSF 2.0 and PCI DSS 4.0. Export CSV or PDF, or have the PDF emailed weekly or monthly. See compliance coverage →

Alerts and day-to-day work

Send new findings to email, Microsoft Teams, Slack or a signed webhook. Repeat alerts are grouped so nobody is flooded. Scans run every six hours by default, or whenever you start one, and a finding you have accepted can be suppressed so the list stays focused.

Read-only by design

Connecting a cloud takes one script in Azure, AWS or Google Cloud Shell. It creates an identity that can only list and read configuration, and Sentrigis tests it before saving. Nothing in your cloud is ever changed. How read-only access works →
